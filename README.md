# Autossential.Workbook.Activities

Autossential.Workbook.Activities provides a powerful set of activities for working with Excel files without requiring Microsoft Excel to be installed. It supports XLSX and XLS formats, making it ideal for server-side or unattended automation scenarios.

✨**Key features:**

- Read and write: Cells, ranges, and tables.
- Formulas: Automatic evaluation of cached values.
- Workbook structure: Add, edit, and format worksheets, manage visibility, configure freeze panes.
- Performance: Optimized for large-scale data processing with smart change detection to avoid unnecessary I/O.
- Best suited for: High-volume processing and automations that cannot rely on Excel being installed.

📄**Full documentation available at:** [https://autossential.github.io](https://autossential.github.io)

🚀 **Installation**

Autossential.Workbook.Activities is available on NuGet. To install in UiPath:

1. Open UiPath Studio.
2. Go to Manage Packages (top ribbon or right-click project → Manage Packages).
3. In the NuGet / All Packages feed, search for Autossential.Workbook.Activities.
4. Select the package and click Install.
5. Save your project — the activities will now appear in the Activities Panel.
